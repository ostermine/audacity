# Stage 05 — Импорт/экспорт .mid, pitch bend/slide, живой MIDI-ввод

Статус: ⬜ **Не начато.** Полировка/расширение.
Зависит от: этапы 1-4.

## Цель

Довести MIDI до «взрослого» уровня: файловый обмен .mid, слайды (pitch bend / перетекание
нот), запись с MIDI-клавиатуры в реальном времени.

## Подзадачи

### 1. Импорт/экспорт .mid
- Нужна MIDI-файловая библиотека. Варианты:
  - Вернуть **portSMF** (то, что использовал au3 NoteTrack) — но это тянет старый мёртвый стек;
  - Взять **компактную header-only** MIDI-либу (проще интегрировать в CMake), парсить в `MidiClip`.
  - Рекомендация: компактная либа, читать/писать напрямую в нашу модель `MidiClip` (в долях,
    конверсия через PPQ файла ↔ доли).
- Импорт: .mid → создать MIDI-трек(и) + заполнить `MidiClip`.
- Экспорт: `MidiClip` → .mid.
- UI: File → Import/Export MIDI (по образцу существующего import/export аудио в
  `src/importexport/`).

### 2. Pitch bend / slide (перетекание ноты в ноту)
- Расширить модель: события pitch-bend в `MidiClip` (время в долях + значение), или флаг «slide»
  на ноте, порождающий bend к следующей ноте.
- Подача в VSTi: в `VST3Wrapper` добавить очередь pitch-bend (VST3: `kLegacyMIDICCOutEvent`/
  `IMidiMapping` для pitch bend, либо note expression `kPitchTuning` на kNoteOnEvent — уже есть поле
  `tuning` в структуре note-on). Для рендера — подавать bend-события параллельно нотам.
- В piano roll: рисование «глайдов» между нотами.

### 3. Живой MIDI-ввод (запись с клавиатуры)
- Здесь пригодится **muse MIDI-модуль**: включить `MUSE_MODULE_MIDI = ON` в корневом
  `CMakeLists.txt` (сейчас OFF, строка ~85). Модуль даёт `IMidiInPort`/устройства
  (Windows winmm), события MIDI 1.0/2.0 (`muse/framework/midi/`).
- Поток: MIDI-вход → события → запись в `MidiClip` активного трека (с квантизацией по SnapType),
  + опционально live-monitoring через привязанный VSTi.
- Осторожно: muse-MIDI не был включён в AU4-сборке; возможны недостающие зависимости —
  проверить сборку после включения флага.

## Тесты
- Импортнуть .mid → ноты появились корректно; экспортнуть → открыть в другом DAW.
- Slide между двумя нотами звучит как глайд.
- Подключить MIDI-клавиатуру → запись играемых нот в трек.

## Заметки
- Это набор независимых фич — можно делать по одной.
- Живой ввод — самый рискованный (включение muse-модуля); делать последним.
