## Известные ограничения V1
- Ноты, нарисованные правее конца клипа-тишины, в превью клипа не видны (клип не растёт).
  Решится этапом 3 (рендер-кэш пересоздаёт клип по длине нот).
- Velocity редактируется только через модель (UI-полосы пока нет).
- Нет выделения/копипаста/мультиредактирования нот, нет триольного снапа.
- Ноты трек-глобальные (от t=0), а не пер-клип — сознательное решение этапа 1.

## Цель

Редактор piano roll: пользователь рисует/двигает/растягивает ноты мышью на сетке
(высота = pitch по вертикали, время = доли по горизонтали), задаёт velocity, длительность,
работает снаппинг по долям.

## Что переиспользовать (готово в коробке)

- **Сетка/зум/скролл времени**: `src/projectscene/view/timeline/timelinecontext.*`
  (есть `BPM`, зум, маппинг время↔пиксели).
- **Снаппинг**: `src/projectscene/view/timeline/snaptimeformatter.*` + `SnapType`
  (`src/projectscene/types/projectscenetypes.h`: Bar/Half/Quarter/Eighth/… + триоли).
- **Тайм-сигнатура/BPM**: `au3-numeric-formats/ProjectTimeSignature` (GetBeatDuration/GetBarDuration).

## План

1. **Отдельная панель редактора** (открывается по даблклику на MIDI-клипе или в отдельной
   докируемой панели). Новый QML-компонент, напр.
   `src/projectscene/qml/Audacity/ProjectScene/pianoroll/PianoRollView.qml` + C++ view-model
   `src/projectscene/view/pianoroll/pianorollmodel.{h,cpp}`.
2. **Вертикаль**: клавиши пианино (0..127 или разумный диапазон), подсветка чёрных/белых,
   опционально «клавиатура» слева.
3. **Горизонталь**: сетка долей/тактов из TimelineContext; вертикальные линии по SnapType.
4. **Ноты**: прямоугольники (x=startBeats→px, w=lengthBeats→px, y=pitch→px). Взаимодействие:
   - клик по пустому месте — создать ноту (со снаппингом старта, дефолт длина = 1 шаг сетки);
   - drag тела — переместить (снап по времени и по pitch-полутонам);
   - drag правого края — изменить длительность (снап);
   - выделение (рамкой/кликом), удаление (Del), копипаст.
5. **Velocity**: полоса снизу (как в FL) — вертикальные столбики на каждую ноту, drag меняет velocity.
6. **Запись изменений в модель** (`MidiClip.notes`) + `projectHistory()->pushHistoryState`/`modifyState`
   для undo и пометки «не сохранено». После правок — триггерить рендер звука (этап 3, render-on-edit).
