# Stage 04 — Степ-секвенсер (драм-машина) + простой сэмплер

Статус: ⬜ **Не начато.**
Зависит от: этапы 1-3 (модель нот, редактирование, звук).

## Цель

Режим «кнопочного» набивания ритма как в FL Studio: строки = инструменты/сэмплы,
колонки = шаги (обычно 16 на такт), клик по клетке = нота на этом шаге. Плюс простой
one-shot сэмплер (проигрывание wav по ноте) для барабанов.

## Ключевая идея

Степ-секвенсер — это **не отдельная сущность**, а **второй вид отображения того же MidiClip**.
Клетка [строка r, шаг s] = нота с pitch, соответствующим строке, и стартом на доле шага s.
То есть grid просто читает/пишет `MidiClip.notes` (из этапа 1), как и piano roll (этап 2).

## План

1. **Grid-вид** (новый QML), напр. `.../stepsequencer/StepSequencerView.qml` + view-model.
   - Ряды: назначаемые «слоты» (Kick/Snare/HiHat/… или произвольные pitch/сэмплы).
   - Колонки: шаги (кол-во = длина клипа × делений; snap = 1/16 по умолчанию).
   - Клетка вкл/выкл → добавить/убрать `MidiNote` (startBeats = шаг × длина шага, lengthBeats = шаг,
     pitch = pitch строки, velocity = дефолт или регулируемый).
   - Подсветка текущего шага при воспроизведении (playhead → индекс шага).
2. **Простой сэмплер** (для драм-машины проще, чем VSTi):
   - Слот = путь к wav + базовый pitch. По ноте — проиграть сэмпл (one-shot), опционально
     ре-питч по разнице нот.
   - Реализация: либо мини-инструмент, рендерящий сэмплы в аудио-кэш (как этап 3, но вместо VSTi —
     микс сэмплов по нотам), либо (позже) через muse FluidSynth/SFZ (тяжелее).
   - Рекомендация для MVP: собственный простой рендер «нота → вставить/смикшировать wav сэмпла
     в позицию» — переиспользует буферный подход этапа 3.
3. **Переключение вида** piano roll ↔ step для одного MIDI-клипа (табы/кнопка).

## Точки интеграции
- Та же модель `MidiClip` (этап 1). Grid и piano roll — два редактора одной модели.
- Playhead/позиция — из playback (`src/playback/`), для подсветки шага.
- Рендер сэмплов в аудио — паттерн буфера/записи в WaveClip из этапа 3.

## Тесты
- Набить ритм кнопками (kick на 1/5/9/13, snare на 5/13, hi-hat каждые 1/16) → play → слышен ритм.
- Переключиться в piano roll — те же ноты видны/редактируются.
- Сохранить/открыть — паттерн на месте.

## Заметки
- Слоты сэмплов и назначение инструментов на строки надо где-то хранить (attachment трека).
- Начать с фиксированных 16 шагов/такт, потом сделать настраиваемым.
